# Aurelio Avila — Community Health Files

This repository provides the default community and security documentation for
public repositories maintained by Aurelio Avila.

## Included policies

- [Security policy](SECURITY.md) for private vulnerability reporting
- [Contributing guide](CONTRIBUTING.md) for proposed changes
- [Code of conduct](CODE_OF_CONDUCT.md) for project participation
- [Pull request template](PULL_REQUEST_TEMPLATE.md) for clear, testable reviews

These files apply automatically to repositories that do not define a more
specific policy. Project-level documentation takes precedence when present.

## Projects

The account focuses on Windows software, privacy-preserving desktop tools,
incident response, detection engineering, and practical security research.
Visit the [GitHub profile](https://github.com/AurelioAvila) for maintained
products, security labs, and technical documentation.
