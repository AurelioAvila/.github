# Contributing

Thank you for taking the time to improve one of my projects.

## Before you start

- Search existing issues before opening a new one.
- Use the repository's issue templates and include reproducible details.
- For a substantial change, open an issue first so the scope can be agreed upon.
- Never include credentials, personal data, private logs, or production secrets.

## Pull requests

1. Keep each pull request focused on one change.
2. Follow the style and structure already used by the repository.
3. Add or update tests and documentation when relevant.
4. Verify that existing checks pass before requesting review.
5. Explain what changed, why it changed, and how it was tested.

Bug reports, documentation improvements, test cases, accessibility fixes, and well-scoped feature proposals are especially welcome. Some repositories use a proprietary license; contribution does not change the license shown in that repository.
